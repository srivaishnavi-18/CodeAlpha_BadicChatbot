# CodeAlpha_BadicChatbot
Basic Chatbot in Python

A simple rule-based chatbot created using Python.

Features

- Responds to basic user messages
- Interactive console chatbot
- Simple and easy-to-use interface
- Exit option using "bye"

Technologies Used

- Python
- Functions
- Loops
- If-Else Conditions
- Input and Output

How to Run

1. Open the project in Python IDLE or any Python editor.
2. Run the "chatbot.py" file.
3. Type messages and interact with the chatbot.
